먼저 결정해야 할 것 — 복사 시점. 이 목업은 답을 정해두지 않았습니다. 시점이 정해져야 버튼 위치·경고 UI·GWT가 모두 따라옵니다.

현재 티켓·C-3·PRD 세 문서가 서로 다른 시점을 가리킵니다. 아래 3장에서 2안을 비교했습니다.

티켓·Jira 본문 어디에도 화면 위치가 없습니다. 매니페스트(test-ids.json)로 확인한 녹음 화면 구조 기준으로 붙일 수 있는 자리는 두 곳입니다.

푸터에는 못 넣습니다. ACLP-4424 시나리오 2-19가 “오른쪽에 ‘검토 완료’와 ‘검토 완료 후 환자에게 발송’ 두 버튼만 표시되고 별도 버튼은 없다”로 확정돼 있습니다. 위 그림은 그 시나리오를 깨는 형태입니다 — B안을 고르면 4424 GWT 2-19를 함께 수정해야 합니다.

  • 모달을 닫으면 복사하려고 다시 열어야 합니다 → PRD V1(조작 수가 늘면 안 쓴다)에 불리.
  • 헤더나 [P] 입력 칸 옆이면 2-19를 건드리지 않지만, 발견성이 떨어집니다.

참고 — 현재 구현된 검토 모달과 4424 목업은 다른 화면입니다. 매니페스트는 확정 / 재편집 / 임시저장 / 인사이트 구조인데, 4424가 Step 1·Step 2 + 검토 완료 / 발송 구조로 갈아엎는 중입니다. B안을 고르면 목업을 4424 v4.1 위에 얹어야 합니다.

이 텍스트에서 확인된 것과 추정한 것

  • 확인 A·P 원문 표기 형식 — 백주연님 「의료 표현 표준화 및 변환 과정」(2026-09-09)의 실제 EMR 사례. OP > ACL-R(auto + BioBrace) + MM repair, knee, Rt. 형식입니다. 4424 목업에서 쓰던 A/S ACL-R + MM repair 시행 예정과 표기가 다릅니다 — 어느 쪽이 실제인지 확인이 필요합니다.
  • 확인 초진 필드 목록 — C-2(도언, 09-16). 초진 H&P / 재진 SOAP 분기는 ACLP-4464 본문에도 있습니다.
  • 확인 유지 대상 Modifier — Rt./Lt. s/p r/o A/S KL G2 POD (PRD V7 · 티켓 원칙 5)
  • 추정 각 필드의 실제 값·문장 형태, 라벨 표기(C.C) vs C.C:), 줄바꿈·들여쓰기. ACLP-4464 산출물 ②(“원하는 정리 형태”)가 아직 안 나왔습니다 — PRD T3에도 “남은 산출물은 ②다”로 적혀 있습니다.

PRD 3곳과 충돌합니다.

  • V3 — 확정 전 문서가 “기록으로 남아서는 안 된다”. EMR에 붙이는 것이 바로 기록으로 남는 행위입니다.
  • 1장 — “EMR 요약과 환자 리포트는 그 확정의 결과로 나간다”는 구조 서술.
  • V1 — 경고 다이얼로그가 붙으면 “클릭 한 번”(원칙 2)이 두 번이 되고, 확정 전 복사가 상시 경로가 되면 매번 뜹니다.

그래도 2안을 택한다면 PRD V3·1장·S9와 티켓 원칙 4를 함께 고쳐야 하고, 그건 완희님 소관입니다.

앞서 제가 과하게 말한 것을 정정합니다. “배경(진료 중 타이핑 제거)과 원칙 4(확정 후)가 서로를 부정한다”고 했는데, PRD V1이 “진료 후 기록 작업도 조작 수가 늘면 직접 타이핑하는 것과 다르지 않아 쓰이지 않는다”로 진료 후 기록 작업을 명시적으로 범위에 넣고 있습니다. 배경은 문제 서술이고, 해결 시점은 진료 후입니다. 충돌은 배경이 아니라 C-3과 PRD 사이에만 있습니다.
