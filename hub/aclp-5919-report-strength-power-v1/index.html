디자인 결정

  • 검사 2종이 각각 지표 1개뿐이라 Humac 블록 구조(차이 상자 + 왼쪽/오른쪽)를 반 폭 블록 2개로 나란히 둡니다. 그래프·표가 없어 전체 폭을 쓰면 오른쪽이 빕니다.
  • 배지는 섹션 이름을 둘로 나눈 「근력」 「파워」, 제목은 폼 그룹명(스플릿 스쿼트 · SL Vertical Jump) 그대로.
  • SL Vertical Jump 는 값이 「오차」라 읽는 법이 다릅니다. 카드 아래에 「작을수록 목표 높이에 가깝습니다」 설명 한 줄을 둡니다(판정이 아닌 지표 정의).
  • 차이 계산은 소수 첫째 자리로 맞춥니다(예: 4.2 − 1.8 = 2.4, 부동소수 오차 노출 방지).

헤드라인 문장 제안 (미정)

  • 「한 발 스플릿 스쿼트로 통과한 무게는 건측보다 7.5kg 가볍습니다.」
  • 「한 발 수직 점프의 목표 높이 오차는 건측보다 2.4cm 큽니다.」
