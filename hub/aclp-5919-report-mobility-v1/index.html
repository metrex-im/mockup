디자인 결정

  • 섹션 하나에 성격이 다른 지표 2개(단일 점수 / 좌우 거리)라서 블록 2개로 나눈다. 블록 머리 배지는 「FMS」 「런지」.
  • FMS 점수는 좌우가 없어 차이 상자를 쓰지 않는다. 0~3 점 중 어디인지만 눈금으로 보여 주고, 점수별 해석 문구는 넣지 않는다.
  • 벽 런지는 등척성 상세면과 같은 「차이 상자 + 왼쪽/오른쪽」. 차이 = |환측 − 건측| cm, 부호 없음.
  • 섹션 분량이 짧아 실제 리포트에서는 앞뒤 검사와 같은 면에 이어 붙는다 (이 목업은 한 면에 단독 배치).

헤드라인 문장 제안 (미정)

  • 「벽 런지 거리는 건측보다 2.5cm 짧습니다.」 — 스포츠 복귀 기능 검사 헤드라인(「건측보다 76cm 짧습니다」)과 같은 틀. FMS 점수는 좌우가 없어 헤드라인에 넣지 않는다.
