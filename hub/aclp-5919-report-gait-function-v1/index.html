디자인 결정

  • 기존 「보행 분석」(Humac 등척성 카드와 같은 문법) 구성을 따라 차이 카드 3장 + 표로 했습니다. 카드 3장 = 표지 핵심 지표와 동일 항목이라 표지 → 상세가 바로 이어집니다.
  • 차이는 결과지 Diff(%)를 그대로 씁니다. Step length(cm)처럼 단위가 다른 지표도 차이는 %라서, 카드·표 모두 차이 옆에 % 단위를 붙였습니다.
  • 카드에 나온 3개는 표에서 뺐습니다(중복 제거). 표는 나머지 좌우 지표 5개만.
  • OptoGait 용어(영문)를 그대로 쓰고, 옆에 회색으로 짧은 우리말 풀이를 붙였습니다.
  • Load response 차이 칸은 빈 값 예시(회색 「-」, 단위 없음)입니다.

헤드라인 문장 제안 (미정)

  • 「한 걸음 길이는 왼쪽과 오른쪽이 10.0% 차이 납니다.」 — 기존 문장표 체계(건측보다 N 적습니다)와 달리 방향이 없는 문장입니다.
