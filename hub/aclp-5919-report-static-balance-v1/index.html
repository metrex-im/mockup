디자인 결정

  • 눈 조건으로 회색 블록 2개(배지 「눈 뜸」 「눈 감음」), 블록 안에 발판 조건 흰 카드 2장을 좌우로 둡니다 → 2×2 가 한눈에 보입니다.
  • 카드마다 Humac 확정 패턴(차이 상자 + 왼쪽/오른쪽)으로 Stability Score 를 크게, Path Length · Average Velocity 는 「상세 지표」 표로 작게 둡니다(Exbody 상세 패턴).
  • 한쪽 값이 없는 조건은 그 칸만 회색 「-」, 차이 상자도 회색 「-」. 조건 자체를 안 했으면 카드째 없음(남은 카드는 반 폭 유지).
  • 「Stability Score」는 영문 그대로 둡니다. 한글 번역어가 금지어(「안정」)와 겹칩니다.

헤드라인 문장 제안 (미정)

  • 「눈을 뜨고 고정 발판에 한 발로 섰을 때 Stability Score 는 건측보다 6% 낮습니다.」 — 4조건 중 어느 것을 쓸지, 4개를 다 쓸지 결정 필요.
