체중 분배 › 환측 체중 · 건측 체중 (kg)표지 · 상세표지: 차이 1칸(파랑). 상세: 차이 상자 + 왼쪽 · 오른쪽 kg + 분배 막대

디자인 결정

  • 지표가 1쌍뿐이라 블록 1개. 흰 카드 왼쪽 = Humac식 차이 상자 + 왼쪽 · 오른쪽 값, 오른쪽 = 그래프 칸 자리에 체중 분배 막대.
  • 막대 칸 이름과 숫자는 kg만 씁니다. %는 폼에 없는 값이라 넣지 않았습니다(아래 확인 1).
  • 막대 색: 왼쪽(환측) 진한 회색 · 오른쪽(건측) 연한 회색 — 값 글자색 규칙과 같게. 가운데 점선은 양쪽이 같을 때의 위치 표시일 뿐 판정 문구는 두지 않습니다.

헤드라인 문장 제안 (미정)

  • 「서 있을 때 왼쪽 다리에 실린 체중은 건측보다 4.6kg 적습니다.」 — 방향(적습/많습)은 두 값의 크기로 정합니다.
