디자인 결정

  • 번호 상자 없이 섹션 이름만 둔다 → 측정 검사(번호 있음)와 성격이 다르다는 것이 바로 보인다.
  • 칩은 회색 중립색. 빨간색·경고 아이콘은 「위험」 판정처럼 읽혀 쓰지 않는다.
  • 체크하지 않은 선택지는 보여 주지 않는다 (「해당 없음」 목록을 나열하지 않음).
  • 선택지 원문은 의료진이 고른 문구이므로 금지어(예: 「정상 수행 제한」의 「정상」)도 그대로 쓴다.

확인 필요 · 환자용 리포트 · 톡톡 발송 여부선택지에 「통증」 「불안정(instability)」 「재손상 공포」 등 헤드라인 정책상 쓰지 않는 표현이 그대로 들어갑니다. 현재 톡톡 안내문 생성 코드도 Red Flag 를 포함해 「· 해당 항목: 운동 중 통증 증가, …」로 보냅니다. 환자에게 보내는 리포트 · 톡톡에 실을지, 의료진 화면 전용으로 둘지 결정이 필요합니다.
확인 필요 · 아무것도 체크하지 않았을 때폼을 열고 아무 항목도 고르지 않은 경우 (A) 섹션 생략, (B) 「체크한 항목이 없습니다」 한 줄 표시 중 선택 필요. 아래 변형 참고. 환자에게 B안은 「문제 없음」 판정처럼 읽힐 수 있습니다.
확인 필요 · 섹션 이름「Red Flag」는 의료진 용어입니다. 환자용이라면 「의료진 확인 항목」 같은 이름으로 바꿀지 검토 부탁드립니다.
확인 필요 · 기타 자유 입력의료진이 쓴 문장을 그대로 실으므로 금지어 정책이 적용되지 않습니다. 입력 안내(환자에게 보인다는 문구)가 필요한지 확인 부탁드립니다.
