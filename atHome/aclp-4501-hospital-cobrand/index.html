항목규칙
구성액티메디 심볼(공식 SVG, 무변형) + 「×」 + 병원 가로형 로고. 세 화면 동일. 앳홈 워드마크 없음.
크기심볼 30px · 병원 로고 높이 30px(홈·프로필), 28px(온보딩). 병원 로고 최대 폭 200px, 초과 시 비율 유지 축소.
병원 로고 소스백엔드 병원 정보의 가로형 로고 이미지. 어드민 등록은 별도 티켓.
로고 등록 + 로드 실패텍스트 폴백(AC-2) — 이미지 요청 실패 · 파일 손상 → 같은 자리에 병원명 15px/700(홈·온보딩), 17px/800 네이비(프로필). 최대 190px 말줄임. 「×」 유지.
로고 미등록앳홈 심볼만(AC-3) — 「×」·병원명 텍스트 없이 심볼 하나. 프로필은 「내 병원」 영역 미표시.
병원 정보 조회 실패병원명도 받지 못하므로 폴백 불가 → 로고 미등록과 동일(심볼만). 홈은 로드맵 아이콘 유지, 헤더 높이 유지.
로딩 중로고 자리 확보. 이미지 도착 전 텍스트·심볼만으로 전환하지 않음.
