항목규칙
구성액티메디 심볼(공식 SVG, 무변형) + 「×」 + 병원 가로형 로고. 세 화면 동일. 앳홈 워드마크 없음.
높이심볼·병원 로고 모두 32px. 홈·정보 확인·프로필 동일.
가로고정 최대 폭 없음. 가용 폭이 상한.
홈·정보 확인 = 화면 폭 − (좌우 여백 + 심볼 + 「×」 + 간격 + 로드맵 아이콘 40px)
프로필 = 카드 폭 − (카드 좌우 여백 + 「내 병원」 라벨)
축소가용 폭을 넘으면 비율을 유지한 채 축소. 이때 높이는 32px보다 작아진다.
텍스트 폴백AC-2. 같은 자리에 병원명 텍스트, 「×」 유지. 가용 폭을 넘으면 한 줄 말줄임(…). 홈·온보딩 15px/700, 프로필 17px/800 네이비.
심볼 단독AC-3. 로고 미등록 또는 병원 정보 확인 불가. 「×」·병원명 텍스트 없이 심볼 하나. 프로필은 「내 병원」 영역 미표시. 홈은 로드맵 아이콘·헤더 높이 유지.
로딩 중로고 자리 확보. 도착 전 텍스트·심볼만으로 전환하지 않음.
홈 헤더좌측 락업 + 우측 40px 원형 로드맵 아이콘 버튼. 「오늘」 제목·「나의 회복 로드맵 ›」 칩 삭제 (AC-4).
